# Mushola Financial

A financial recording web app for a mushola.

## Stack

- Next.js
- TypeScript
- Google Sheets API
- Vercel
- GitHub

## Database

Google Sheets is the source of truth. The first database table is:

01_TRANSAKSI_UANG

## Local environment

Copy .env.example to .env.local and fill the Google service-account values locally.

Never commit the service-account JSON file or private key to GitHub.
